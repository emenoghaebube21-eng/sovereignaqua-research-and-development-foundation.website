Research-to-Impact Model

Evidence first. Implementation second.

The Foundation can use a common pathway for each programme: define the problem, conduct or coordinate research, validate findings, develop a pilot, measure outcomes and publish appropriate evidence.

  • Problem definition and baseline assessment
  • Research, field observation and technical analysis
  • Pilot design and responsible implementation
  • Monitoring, evaluation and documented outcomes
  • Knowledge transfer and scale-up where evidence supports it

Publication and evidence standard

Only verified publications, project outcomes, partnerships, statistics and institutional claims should be presented as established facts. Developing initiatives should be clearly labelled as proposed, planned or in development.

The field images supplied for future programme presentation should likewise be identified as Foundation-owned/project evidence only when that provenance has been confirmed.
